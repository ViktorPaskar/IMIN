# IMIN — imin.wtf

Сайт IMIN, полностью переделанный по Brand Guidelines v2.0 (октябрь 2026).
Статический сайт без сборки: `index.html` + `assets/`. Его можно положить на любой хостинг (Vercel, Netlify, GitHub Pages, Cloudflare Pages, nginx).

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Структура

```
index.html              разметка и все тексты
assets/css/style.css    дизайн-токены бренда, вёрстка, адаптив
assets/js/main.js       анимации, паттерн The Beat, форма
assets/vendor/          GSAP 3.13 (+ ScrollTrigger, SplitText), Lenis 1.3 — локальные копии
assets/img/             favicon.svg, og.png (превью для соцсетей)
```

## Бренд

| Токен       | Цвет      | Роль |
|-------------|-----------|------|
| Midnight    | `#0B0A14` | фон |
| Paper       | `#F4EFE7` | текст на тёмном, светлые секции |
| Ultra       | `#4B2BFF` | один блок на экран (Wedge/Moat, карточка «Your audience») |
| Haze        | `#9C8CFF` | цветной текст и ссылки на тёмном |
| Doorlight   | `#FF9E1B` | одно действие на экран (кнопка «Let’s talk» / «I’m in») |

Шрифты — Barlow Condensed 700/800 (заголовки, всегда капсом) и DM Sans 400–700 (текст), из Google Fonts.
Иконки — Phosphor Light, встроены SVG-спрайтом. Логотип перенесён из брендбука векторно, без перерисовки.
Паттерн The Beat генерируется в коде из штрихов I/M/I/N: каждый второй ряд сдвинут на полтакта, в каждом кадре один штрих Doorlight.

## Анимации

- прелоадер: такт IMIN встаёт как эквалайзер, загорается «I» цвета Doorlight;
- hero: живой паттерн-эквалайзер, параллакс при скролле и движении мыши;
- бегущая строка, которая реагирует на скорость скролла;
- текст «The idea» проявляется по словам при чтении;
- раздел продукта закреплён и листается по горизонтали (на мобильных — вертикальный стек);
- прогноз, счётчики, переключатели каналов и Poster Studio анимируются при появлении; кнопки вайба перекрашивают постеры;
- параллакс телефона в разделе приложения, «маршрут» FR → ES → PT рисуется при скролле;
- кастомный курсор, магнитные кнопки, шум-зерно, индикатор прогресса.

Учитывается `prefers-reduced-motion`: при этой настройке анимации отключаются, а контент сразу виден полностью.
Если скрипты не загрузятся, страница всё равно остаётся читаемой.

## Форма «Join the founding cohort»

Настраивается атрибутами на `<form id="apply-form">` в `index.html`:

- `data-endpoint="https://…"` — если задан, заявка уходит туда POST-запросом с JSON (Formspree, Make, Zapier, свой API);
- `data-email="hello@imin.wtf"` — если endpoint пуст, открывается почтовый клиент с заполненным письмом на этот адрес.

**Перед запуском проверьте адрес почты** — `hello@imin.wtf` поставлен как предположение.

## Что проверить перед публикацией

- `data-email` / `data-endpoint` формы;
- `og:image` указывает на `https://imin.wtf/assets/img/og.png`;
- цифры в карточках продукта (412/600, €6,180 и т.п.) помечены как *Illustrative data*: это демо интерфейса, не реальные показатели.
